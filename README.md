# 🔵 Bluetooth File Transfer Tool

![Platform](https://img.shields.io/badge/OS-Windows-blue)
![Status](https://img.shields.io/badge/Status-Active-brightgreen)

**Bluetooth 転送ツール**は、Wi-Fiやインターネット環境がない場所でも、Bluetoothを使用してWindows PC間で直接・安全にファイルを送受信できるアプリケーションです。

実行ファイルのダウンロード. 
https://github.com/k518-2026/BluetoothFileTransfer/releases

詳細な図解入りマニュアルは [`manual.html`](manual.html) をご覧ください。

---

## ✨ 特徴 (Features)
- **インターネット不要**: 完全オフラインでセキュアに転送可能
- **かんたん操作**: ドラッグ＆ドロップの直感的なインターフェース
- **自動保存**: 受信したファイルは自動的に「ダウンロード」フォルダへ保存
- **安全設計**: 指定された安全なファイル形式のみを許可

---

## ⚠️ 【重要】事前準備（初めて使うとき）

Windowsの初期設定では、他のPCからのBluetooth検索がブロックされています。**ファイルを受信する側のPC**で、必ず以下の設定を行ってください。

1. Windowsのスタートメニューから **「設定（歯車マーク）」** を開く
2. **「Bluetooth とデバイス」** > **「デバイス」** をクリック
3. 画面を下へスクロールし、**「Bluetooth デバイスの検出」** を探す
4. 設定を「既定」から **「詳細」** に変更する

> 💡 ※画像での詳しい解説は `manual.html` の「2. 【重要】事前準備」をご参照ください。

## 🚀 使い方 (Usage)

### 📥 ファイルを受信する方法
特別な操作は必要ありません。
1. 本アプリを起動します。
2. 画面右下のログに `[ファイルの受信待機を開始しました]` と表示されていれば準備完了です。
3. ファイルを受信するとプログレスバーが動き、完了するとPCの **「ダウンロード」** フォルダに自動保存されます。

### 📤 ファイルを送信する方法
1. アプリ左側の **「デバイスを検索」** ボタンをクリックします。
2. リストに相手のPCの名前が表示されたら、クリックして選択状態にします。
3. 送信したいファイルを、画面右側の「ドラッグ＆ドロップエリア」にマウスで引き込み、指を離します。
4. **（初回のみ）** 画面の右下などに、Windowsから **「デバイスの追加（ペアリング）」** の通知が出ます。両方のPCで「許可（はい）」をクリックしてください。
5. 転送が開始され、青いプログレスバーが100%になれば送信完了です。

---

## 📄 対応しているファイル形式

セキュリティ確保のため、以下の拡張子のファイルのみ送信可能です（`.exe`などの実行ファイルは自動でブロックされます）。

- ドキュメント: `.pdf`, `.docx`, `.xlsx`, `.md`, `.txt`
- データ: `.csv`, `.json`
- 画像: `.gif`

## 🛠️ トラブルシューティング

**Q. 検索しても相手のPCがリストに出てきません**
> **A.** 受信側PCの「事前準備（Bluetoothデバイスの検出設定）」が「詳細」になっているか確認してください。それでも出ない場合は、Windows標準の設定画面から手動でペアリングを一度完了させてから、再度アプリで検索してください。

**Q. 過去に接続したPCにファイルを送るとエラーになります**
> **A.** 相手のPCの電源が切れているか、アプリが起動していない可能性があります。通信できないデバイスを選択した場合、クラッシュを防ぐために自動でリストから削除されます。

**Q. 「フォーマットエラー」と表示されます**
> **A.** 対応していない拡張子（`.png` や `.zip` など）をドロップしていませんか？対応ファイルの一覧をご確認ください。
